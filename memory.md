# RealJanNetra Project Rules

## Mandatory Protocol
- **READ THIS FILE** before starting any coding session.
- The agent must adhere to the rules defined here strictly.

## Development Phase
- **Current Focus:** Frontend development.
- **Workflow:** After the initial setup of both backend and frontend, all effort will be directed towards the frontend until further notice.
- **Dynamic Integration:** Backend and Frontend must be designed to be dynamically connected. Use environment variables (e.g., `VITE_API_URL`) to ensure the frontend can easily switch between development and production backend endpoints.

## Project Structure
- `backend/`: Node.js/Express/MongoDB setup.
- `frontend/`: React/Vite/TypeScript setup.

## Next Steps
1. Complete Backend initialization.
2. Complete Frontend initialization.
3. Switch focus entirely to Frontend development.
